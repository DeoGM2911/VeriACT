Replace a note file with new content. Costs no game action and ends no turn.

`file` — `GUIDE.md` or `WORKING.md`.
`content` — the complete new contents of that file.

**Whole-file replace.** What you send becomes the file; anything you leave out is gone. If you are
amending rather than starting over, `read_notes` first and send back the whole thing with your
changes in it.

Write when you have learned something worth keeping — a rule confirmed or contradicted, a level
started or completed, the game ended, your plan changed. Not on a schedule, and not when nothing
new happened.

Write for a reader who does not have the reasoning that produced the note — once this conversation
has been trimmed, that reader is you. Exact numbers survive being re-read; "the piece near the
middle-left" does not.

Anchor every rule to the specific object or feature it applies to. "ACTION1 moves up" stops being
usable the moment a second object can move — write "ACTION1 moves the blue 2x2 block up" instead,
and reuse that exact name (colour, shape, size are usually enough) every time you refer to it
again. An untied rule has to be re-derived from scratch the next time it matters.

If you notice yourself restating the same thing at length, stop and write a shorter version — a
short file that says something once is worth more than a long one that keeps circling it.
